## Project Overview

This repository is the **analysis half** of a two-repo case. The findings feed the rules of a self-hosted workout tracker, which in turn is the data source going forward.

| Half | Scope | Where |
| :--- | :--- | :--- |
| **Product** | Self-hosted workout tracking app (React PWA, PHP, SQLite) implementing the findings as rules | [`gym-tracker-app`](https://github.com/kaywiegand/gym-tracker-app) |
| **Analysis** *(this repo)* | Training load, strength progress and body composition of one person | [`gym-tracker-analysis`](https://github.com/kaywiegand/gym-tracker-analysis) |
